# OnboardingAI — Quick Guide (Non-Technical)

This is a simple guide for sales, ops, and onboarding teammates.

---

## What OnboardingAI Does

OnboardingAI helps you:
- Find Indian universities
- Research each university automatically
- Draft personalized outreach emails
- Track replies and move leads through pipeline stages
- Generate proposals and book meetings

---

## Daily Workflow (10–20 Minutes)

1. Open **Universities** and click **Sync UGC** (if you need fresh leads).
2. Go to **Enrichment** and run **Deep Enrichment** on a small batch (5–10).
3. Go to **Outreach** and start sequence for universities in **Ready to Sequence**.
4. Go to **Approvals** and review AI-drafted emails.
5. Use **Approve & Send** (or edit first) to send outreach.
6. Check **Analytics** for replies, opens, bounces, and funnel movement.

---

## Team Rules of Thumb

- Always review emails before sending.
- Start small, then scale once messaging works.
- If a university is not a fit, move it to **Skipped**.
- If someone asks to stop, mark as **Not Interested**.
- Keep follow-ups polite and short.

---

## Pipeline Stages (Simple Meaning)

- **Ready to Sequence** — Ready for first outreach
- **Outreach Active** — Emails are in progress
- **Replied** — Contact responded
- **Meeting Booked** — Call scheduled
- **Proposal Sent** — Proposal delivered
- **Closed** — Finished (won or archived)
- **Not Interested** — Declined or opted out
- **Skipped** — Intentionally excluded

---

## When Replies Come In

The system classifies replies (interested, meeting request, info request, not interested, etc.).

If confident context is available, it can auto-send a polite response for positive replies.

If a reply is unclear or unmatched, review it manually from the dashboard queues.

---

## Proposal Workflow (Simple)

1. Open **Proposals**
2. Click **Generate Proposal**
3. Select university (and stakeholder if available)
4. Preview, adjust if needed, then send

### When a Meeting is Requested
When a stakeholder replies asking for a meeting, the system creates a **draft proposal** flagged as **Meeting Pending**.

To confirm the meeting:
1. Find the proposal card showing **Meeting Pending**.
2. Click **Confirm Meeting & Create Meet Link**.
3. Pick a **date, time, and duration** (15–60 minutes).
4. Click **Confirm & Generate Link**.
5. The system creates a Google Calendar event with a Meet link.

If you need to reschedule, click **Reschedule Meeting** on any confirmed proposal.

---

## If Something Looks Wrong

1. Check **Settings** for missing/expired keys
2. Check **Approvals** for unsent drafts
3. Check **Analytics** for bounces/failures
4. Check **Outreach** for unclassified replies

If still blocked, capture the visible error and share it with the tech team.
